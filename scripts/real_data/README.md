# Legacy credentialed extension

These scripts and `scripts/run_v4_real_data.py` retain the original MIMIC/eICU
engineering workflow for a future credentialed external-validation extension.
They are not invoked by the primary quick-start. Use `scripts/physionet2019/`.
Historical report generation can recreate old documents; do not run it as part of
the PhysioNet pivot or mistake dry-run outputs for real observations.
